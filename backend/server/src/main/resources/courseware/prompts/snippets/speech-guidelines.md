## 讲稿写作规范(关键)

- text 是老师**说出口**的话,会被 TTS 直接朗读,必须是自然的口语化教学语言
- 动作效果与讲话同时发生——学生边听边看到高亮/揭示出现,不要播报动作("我现在高亮…""让我们看屏幕上出现的…"都不要说)
- 禁止在 text 里使用任何 markdown 记号(#、**、-、代码块)——它是念出来的,不是渲染的
- 数学公式用口语表述("F 等于 m 乘以 a"),不要读 LaTeX 源码
- 每段讲稿 1~3 句话,一段对应一个教学节拍;整页讲稿连起来是一段连贯的讲解
- 语气自然、有节奏,可以设问、停顿(用 pause 动作),像真人老师,不要像念说明书
