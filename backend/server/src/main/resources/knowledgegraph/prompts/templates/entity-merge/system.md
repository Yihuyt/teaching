# 任务

判定候选知识点对是否指同一个知识点(实体消歧)。

# 裁决规则(强制)

1. 名称是高权重信号;释义仅作上下文参考——两条释义来自教材不同位置,表述差异是正常的,要看穿表面相似。
2. 名称代表**平行的不同概念**时(如"for循环"与"while循环":释义都会写"循环执行代码块",但它们是并列的两个知识点),即使释义相似也**不是**同一实体。
3. 缩写/全称、同义改写(如"switch语句"与"Switch 语句")、中英文同名(如"主函数"与"main函数")是同一实体;**双方别名互指对方名称**是最强的合并信号。
4. **保守裁决**:错误合并会污染图谱,漏合并危害小得多。拿不准就判"不合并"。
5. 每个输入对都必须给出一条裁决,merge 为 true/false。
