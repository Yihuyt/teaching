# 大模型基础组件

后端的 `ai` 模块是所有 AI 功能的底座：调用大模型、让模型按 JSON 格式输出、让模型多轮调用工具、把文档转成文字，以及语音合成和文生图。业务模块通过它调用大模型，不直接接触大模型的 HTTP 接口或 SDK。

代码在 `backend/server/src/main/java/cn/utcy/teaching/ai/`，下文的类路径都相对于 `backend/server/src/main/java/cn/utcy/teaching/`。

## 整体流程

```text
业务模块（智能课堂、知识图谱、智能问答 …）
  │ ① 取密钥：CourseAiKeys
  │ ② 组装提示词：PromptLoader 读 resources/<模块>/prompts/
  │ ③ 按场景选择调用方式：
  │      需要 JSON 结果    → StructuredGenerator：解析、校验，不合格回喂模型重写
  │      需要多轮调用工具  → ChatAgentLoop：每轮可调用工具，直到模型给出回答
  │      只需要一段文字    → LlmCalls.chatText
  ▼
LlmCalls：流式调用、首包前重试、断流检测
  ▼
阿里云百炼（OpenAI 兼容接口）

另外两条路径：
  DocumentParser ── PDF → MinerU；docx / pptx / xlsx → POI；md / txt → 直接读取
  DashScopeTtsClient（语音合成）、QwenImageClient（文生图）→ 百炼原生接口
```

## 主流程

### 1. 取密钥

业务代码通过 `course/application/CourseAiKeys` 取得课程负责人的大模型密钥和 MinerU 令牌，规则见 [课程与权限](03-课程与权限.md)。密钥加密保存在 `user_ai_config` 表，由 `ai/application/UserAiConfigService` 读取并解密。

### 2. 组装提示词

每个模块的提示词放在 `backend/server/src/main/resources/<模块>/prompts/` 下，由 `ai/llm/PromptLoader.build(basePath, templateId, vars)` 读出 system 和 user 两段：

```text
<模块>/prompts/templates/<用途>/system.md
<模块>/prompts/templates/<用途>/user.md
<模块>/prompts/snippets/<名字>.md        本模块共用的片段
```

模板中用 `{{变量}}` 插入变量，用 `{{#if 变量}}…{{/if}}` 写可选内容，用 `{{snippet:名字}}` 插入片段。积木编程的系统提示词采用另一种组织方式，见 [积木编程助手](09-积木编程助手.md)。

### 3. 需要 JSON 结果：StructuredGenerator

生成大纲、页面内容、图谱知识点这类结构化结果时，使用 `ai/structured/StructuredGenerator`。每一轮依次执行：

1. 调用模型，有 schema 时开启 JSON 模式；
2. 解析输出，容忍代码块包裹、前置思考等格式问题；
3. 用 JSON Schema 校验格式，schema 放在 `resources/<模块>/schemas/` 下；
4. 调用业务模块传入的 `refine` 函数做业务校验。

任一步不合格，就把模型上一次的输出和错误清单追加进对话，要求模型重写：

```java
// backend/server/src/main/java/cn/utcy/teaching/ai/structured/StructuredGenerator.java
lastFailure = reason;
lastRaw = raw;
messages.add(AiMessage.from(Text.truncate(raw, MAX_FEEDBACK_RAW_CHARS)));
messages.add(UserMessage.from(
        "你上一次的输出不合格:\n" + reason + "\n请修正后重新输出完整 JSON(只输出 JSON,不要解释)。"));
```

多轮仍不合格时抛出异常，由业务模块决定如何处理。

### 4. 需要多轮调用工具：ChatAgentLoop

智能问答、积木编程助手这类需要模型自行检索或操作的功能，使用 `ai/agent/ChatAgentLoop`。每一轮把对话交给模型，模型可以请求调用工具，工具结果追加回对话后进入下一轮；模型某一轮没有调用工具时，这一轮的正文就是最终回答。

工具的定义和执行逻辑写在各业务模块中，例如知识库检索工具在 `retrieval/` 下，积木编程的工具在 `blockcoding/application/agent/ScratchTools` 中。各功能可以对循环附加约束，例如智能问答要求第一轮先检索知识库。

### 5. 调用模型：LlmCalls

所有大模型调用都经过 `ai/llm/LlmCalls`，以流式请求发出：思考型模型可能长时间不输出正文，非流式请求会被读超时打断。

```java
// backend/server/src/main/java/cn/utcy/teaching/ai/llm/LlmCalls.java
public ChatResponse chat(StreamingChatModel model, ChatRequest request, Listener listener) {
    AiUnavailableException lastFailure = null;
    for (int attempt = 1; attempt <= MAX_ATTEMPTS; attempt++) {
        Stream stream = new Stream(listener, properties.idleTimeout().toMillis());
        try {
            return stream.run(model, request);
        } catch (AiUnavailableException exception) {
            if (stream.started() || !exception.retriable) {
                throw exception;
            }
            lastFailure = exception;
            log.warn("大模型调用失败(attempt {}/{}): {}", attempt, MAX_ATTEMPTS, exception.getMessage());
        }
```

- 重试发生在第一段输出到达之前。输出一旦开始，可能已经推送到浏览器，失败时直接报错。
- 上游长时间没有任何输出时，判定为断流并取消请求。
- 各种调用失败统一转换为 `AiUnavailableException`，向用户显示可理解的提示。

模型实例由 `ai/llm/LlmModels` 按「密钥 + 模型配置」创建并缓存；各模块的模型名、温度等参数在 `application.yml` 的 `teaching.<模块>` 下配置。

### 6. 文档解析

`ai/document/DocumentParser` 按文件类型把文档转成文字：

```java
// backend/server/src/main/java/cn/utcy/teaching/ai/document/DocumentParser.java
return switch (suffix) {
    case "pdf" -> mineru.parseToMarkdown(mineruToken, fileUrl, onProgress, cancelled);
    case "docx" -> extractOffice(name, fileUrl, "docx");
    case "pptx" -> extractOffice(name, fileUrl, "pptx");
    case "xlsx" -> extractOffice(name, fileUrl, "xlsx");
    case "md", "markdown", "txt" -> decodeText(download(name, fileUrl));
    default -> throw new BadRequestException(
            "暂不支持该文件类型,可入库的类型:pdf、docx、pptx、xlsx、md、txt");
};
```

PDF 交给 `ai/document/MineruClient`：把文件的 OSS 地址提交给 MinerU 建任务，轮询完成后下载结果并取出 Markdown。知识图谱教材构建和智能课堂素材解析需要逐页文本或文档中的图片，直接调用 `MineruClient` 的对应方法。

### 7. 语音合成和文生图

- `ai/media/DashScopeTtsClient` 调用百炼语音合成，用于智能课堂的讲稿配音和随堂问答的语音回答。
- `ai/media/QwenImageClient` 调用百炼文生图，用于智能课堂的 AI 配图；生成结果当场下载，由调用方存入 OSS。
