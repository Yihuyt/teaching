# 智能问答

教师在课程中配置问答助手并挂载知识库，学生与助手多轮对话；助手先检索知识库再回答，回答附带可点开的引用来源。本文说明一次提问是怎样完成的。

后端在 `backend/server/src/main/java/cn/utcy/teaching/tutor/`，前端在 `frontend/src/features/tutor/`，提示词在 `backend/server/src/main/resources/tutor/prompts/`。检索工具见 [知识库与检索](06-知识库与检索.md)，智能体循环 `ChatAgentLoop` 见 [大模型基础组件](01-大模型基础组件.md)。

## 整体流程

```text
学生提问 ──→ TutorChatService.sendSse
               请求线程中检查：会话属于本人、助手可用、课程负责人已配置密钥
               ↓ 流式任务
             1. 保存提问，组装历史（过长时把较早的消息压缩成摘要）
             2. 预检索：用学生原话检索挂载的知识库
             3. ChatAgentLoop：第一轮强制模型检索 → 可多轮检索 → 最终回答（流式推送）
             4. 保存回答和引用来源
             5. 会话的第一问：为会话生成标题
```

助手由教师在课程管理页配置：名称、补充要求、模型参数、挂载的知识库，以及是否对学生可见。补充要求只进入系统提示词，学生看不到。

## 主流程

### 1. 提问前的检查

`application/TutorChatService.sendSse` 在请求线程中完成全部检查：会话属于提问者本人；助手对当前用户可用，学生要求课程可学且助手对学生可见；问题不为空；课程负责人已配置大模型密钥。检查不通过时返回普通的错误响应，通过后才开始流式任务。

本轮使用的助手配置由 `TutorAssistantService.mounts` 组装，挂载的知识库中只有索引就绪的进入本轮。

### 2. 保存提问与组装历史

提问先写入 `tutor_message`，再由 `TutorContextBuilder` 决定带入多少历史。历史按上下文窗口的预算带入；超出预算时，保留最近的消息，把更早的部分交给 `summary` 提示词压缩成摘要，存在会话上，之后的回合把摘要和未压缩的消息一起带入。本次提问作为最后一条用户消息带上。

### 3. 预检索与第一轮强制检索

- 预检索：用学生的原话在挂载的知识库中各检索一次，结果附在用户消息之后。
- 第一轮强制检索：学生的问法常与资料的措辞不同，按原话检索可能落空，因此挂载了知识库时，第一轮强制模型自己拟定查询词调用 `rag` 检索。开启深度思考的模型不支持强制调用工具，这类助手只依靠提示词中的要求。

```java
// backend/server/src/main/java/cn/utcy/teaching/tutor/application/TutorChatService.java
// 挂了知识库就让模型第一轮先自己写查询词检索一次:学生的问法常和材料措辞不同,按原话预检索会落空;
// 思考模式不支持强制工具,开了思考的助手只能靠提示词
ChatAgentLoop.Config loopConfig = ChatAgentLoop.Config.of(mounts.maxRounds(), properties.contextWindow());
if (!retrievalMounts.knowledgeBases().isEmpty() && !mounts.model().reasoning()) {
    loopConfig = loopConfig.withFirstRoundToolRequired();
}
```

系统提示词由 `chat/system.md` 组装：助手名称、挂载的知识库、可用工具，以及教师的补充要求。

### 4. 智能体循环与流式回答

`ChatAgentLoop` 执行多轮：模型可以多次调用 `rag`，换不同的查询词检索；某一轮不再调用工具时，这一轮的正文就是最终回答。`TutorChatService` 把思考、正文、工具调用等过程实时推送给前端，事件格式见 [前后端对接](../03-前后端对接.md)。

### 5. 引用来源

一轮问答中，预检索和每次 `rag` 调用共用一个 `SourceRegistry`，检索到的段落依次编号为 `source-1`、`source-2`……。提示词要求模型在引用处写出编号，前端 `TutorChatPanel.vue` 把编号替换为可点击的角标，来源列表由 `TutorSources.vue` 显示。

### 6. 保存回答

```java
// backend/server/src/main/java/cn/utcy/teaching/tutor/application/TutorChatService.java
List<Map<String, Object>> sources = registry.all();
TutorMessageEntity assistant = sessions.append(turn.sessionId(), "assistant", outcome.finalText(),
        toJson(sources), toJson(trace(outcome, narrations)));
learningEvents.record(new LearningEvent(turn.courseId(), turn.accountId(),
        LearningEventType.TUTOR_QUESTION_ASKED, turn.sessionId(), Map.of()));
emit.accept(Map.of("type", "done", "assistantMessageId", assistant.getId(), "sources", sources));

if (history.isEmpty()) {
    String title = new TutorTitleService(llm, prompts, llmModel)
            .generate(apiKey, turn.question(), outcome.finalText());
```

- 回答连同引用来源和过程记录一起保存，前端 `TutorTrace.vue` 据此展示检索过程。
- 每次提问记录一条学情事件。
- 会话的第一问回答完成后，`TutorTitleService` 为会话生成标题，显示在会话列表中。

教师可以在课程管理页的「智能问答」中查看课程内的全部会话。
